# Reference documents

Put the source PDFs here so the citations in the engine can be traced. File names the
register (docs/references.md) expects:

| File | Document |
|---|---|
| `4.10_Constructed_Wetlands.pdf` | Design guideline chapter 4.10, Constructed Wetlands |
| `4.11_Edge_Engineering.pdf` | Design guideline chapter 4.11, Edge Engineering |
| `4.12_Inline_SWD_Treatment.pdf` | Design guideline chapter 4.12, In-line SWD Treatment |
| `TR-55_Manual.pdf` | NRCS (1986) Urban Hydrology for Small Watersheds, TR-55 |
| `Runoff_volume_metric_Appendix.pdf` | Bengaluru lake-cascade model appendix (runoff, wastewater, water balance) |

TR-55 is a US government publication. Check the licence of the guideline chapters before
committing them to a shared repository.
